# Grama Waste Tracker ♻️

## 📌 Overview
Grama Waste Tracker is an Android application designed for village waste collection management. It helps track waste collection routes, monitor workers, and improve cleanliness using Firebase and Google Maps integration.

## 🚀 Features
- Real-time waste collection tracking
- Google Maps integration
- Firebase Authentication
- Location monitoring
- User-friendly Android UI
- Waste collection status updates

## 🛠️ Tech Stack
- Kotlin 
- Android Studio
- Firebase
- Google Maps API
- Gradle
